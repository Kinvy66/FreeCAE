# 函数式几何模块设计指导文档

## 一、设计目标

构建一个类似 COMSOL 的函数式几何管理模块，具备以下特性：

-   不保存中间几何实体
-   仅保存"几何操作节点"
-   支持修改中间步骤并自动重建
-   支持 DAG 依赖结构
-   支持 Selection 规则（避免拓扑命名问题）
-   支持局部重建和缓存
-   可扩展到 OCC 内核

------------------------------------------------------------------------

## 二、函数式几何思想

几何不是实体集合，而是操作序列的函数结果：

G = OpN(OpN-1(...Op1(∅)...))

系统仅保存： - 操作类型 - 参数 - 依赖关系

不保存： - Face ID - Solid 实体 - 中间 Body

------------------------------------------------------------------------

## 三、DAG 结构

DAG = Directed Acyclic Graph（有向无环图）

特点： - 每个节点可有多个输入 - 不允许循环依赖 - 支持分支与汇合 -
可拓扑排序执行

示例结构：

Block1 ──┐ ├── Union ── Fillet Block2 ──┘

------------------------------------------------------------------------

## 四、核心数据结构设计

### 1. 几何节点

``` cpp
enum class GeoOpType {
    Block,
    Cylinder,
    Union,
    Difference,
    Fillet,
    Import
};

struct GeoNode {
    int id;
    GeoOpType type;
    std::string name;
    ParamSet params;
    std::vector<int> inputs;
};
```

------------------------------------------------------------------------

### 2. DAG 管理器

``` cpp
class GeometryTree {
public:
    std::unordered_map<int, GeoNode> nodes;
    std::unordered_map<int, std::vector<int>> adjacency;

    void addNode(const GeoNode& node);
    std::vector<int> topoSort();
};
```

## 五、构建引擎

### 1. 构建流程

``` cpp
TopoDS_Shape GeometryModule::build()
{
    auto order = tree.topoSort();

    for (int id : order)
    {
        nodeResults[id] = applyNode(tree.nodes[id]);
    }

    return nodeResults[lastNodeId];
}
```

## 六、修改中间步骤机制

流程：

1.  修改节点参数
2.  标记该节点为 dirty
3.  标记所有下游节点 dirty
4.  重新计算 dirty 节点

### Dirty 标记示例

``` cpp
void markDirty(int id)
{
    dirtyNodes.insert(id);
    for (auto child : downstream[id])
        markDirty(child);
}
```

------------------------------------------------------------------------

## 七、Selection 规则系统

避免使用固定 FaceID。

定义规则接口：

``` cpp
class SelectionRule {
public:
    virtual TopTools_ListOfShape eval(const TopoDS_Shape& shape) = 0;
};
```

规则在每次重建时重新计算，从而避免拓扑命名问题。

------------------------------------------------------------------------

## 八、缓存系统

``` cpp
std::unordered_map<int, TopoDS_Shape> nodeResults;
```

修改节点时，清除其下游缓存，重新计算。

------------------------------------------------------------------------

## 九、模块接口示例

``` cpp
class GeometryModule {
public:
    int addBlock(...);
    int addUnion(int a, int b);
    int addFillet(int input, SelectionRule rule);

    void updateNode(int id, ParamSet p);
    TopoDS_Shape build();

private:
    GeometryTree tree;
    std::unordered_map<int, TopoDS_Shape> nodeResults;
};
```

## 十、函数式 vs 对象式对比

  维度         函数式   对象式
  ------------ -------- --------
  数据保存     操作     实体
  修改方式     重算     直接改
  拓扑稳定性   高       低
  参数驱动     强       一般

------------------------------------------------------------------------

## 十一、核心总结

函数式几何系统本质是：

DAG + 重建引擎 + 规则选择系统

它管理的是"操作依赖关系"，而不是几何实体。
